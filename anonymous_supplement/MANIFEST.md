# Manifest

Each row maps a paper claim or table/figure to a supplement file, the source file
in the working repository (where applicable), a status, notes, and an
anonymization-risk assessment.

## Status legend

- **FOUND** — copied from an existing cached evaluation artifact in the working
  repository that appears real and safe.
- **SUMMARY_ONLY** — generated as a small aggregate summary from paper-reported
  values, not raw outputs. The supplement file says so inline.
- **PARTIAL** — some supporting material found and copied; some pieces are
  paper-reported only and flagged inline.
- **MISSING** — no artifact found in the working repository; documented but
  not surfaced as a numeric value.

## Anonymization-risk legend

- **low** — no identifiers expected; verified clean by pattern scan.
- **medium** — content-only file but generated by the authors; a determined
  adversary could in principle stylistically fingerprint it.
- **high** — would not be included; entries with this risk are not in the
  supplement.
